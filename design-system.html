Design system

The site is the gallery wall: a warm grey background, texts that read like museum labels and nothing that competes with the paintings. Every value is a token in src/styles/global.css; components only use var(--…). Use the switch in the top bar to see the dark mode.

ColorsTypeSpacingLayoutMotionPatternsComponents

Colors

Each color has a light and a dark value; the page follows the visitor's system until they use the switch. Wherever the wall shows it carries --grain, a very fine noise like plaster or paper, so the background is never flat: background: var(--wall) var(--grain). Never over a work.

  • --wallPage background, the wall in the artwork photos
  • --paperCards, the cookie notice
  • --inkText, buttons, picked options
  • --mutedSecondary text, labels
  • --lineSeparators, field lines, outlines
  • --availableGreen dot of available works
  • --accentForm errors only
  • --nightImage viewer and video players (same in both modes)
